# Product roadmap

Priorities are grouped by user value and cross-platform fit. The shared core remains the source of truth; each platform gets the interaction that best fits its input model.

## Now

- Make transaction capture fast: remembered payees, smart category suggestions, splits, transfers, notes, and receipt-friendly entry.
- Make sync understandable: clear online/offline/local-only states, retry paths, conflict-safe refresh, and last-sync context.
- Make review efficient: search, filters, reconciliation, uncategorized views, and accessible transaction tables.
- Keep the mobile home focused on balance, recent activity, and the next useful action; keep desktop home optimized for review density.

## Next

- Goals, sinking funds, debt and loan planning.
- Recurring schedules with calendar context and safe post/skip controls.
- Tags, saved filters, saved reports, and richer export/import flows.
- Household sharing with explicit roles, device management, and audit history.
- Multi-currency accounts with clear conversion and reporting rules.
- Widgets, Shortcuts, and background refresh parity across native clients.

## Later

- Privacy-preserving assistance that explains spending and suggests actions without sending budget contents to a third party.
- A plugin and integration surface with explicit permissions and sync-safe contracts.
- Deeper accessibility and localization audits across every platform.

A roadmap item is ready for implementation when its shared data shape, sync behavior, offline semantics, mobile interaction, desktop interaction, native requirements, and validation plan are written down.
